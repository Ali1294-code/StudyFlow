# StudyFlow

> A student productivity dashboard built as a practice project after completing an HTML & CSS course.

---

## About The Project

**StudyFlow** is a modern student productivity dashboard designed to help university students organize their courses, tasks, schedules, and study progress.

This project was created primarily for **learning and practice purposes**.

I recently completed an **HTML & CSS course**, and I built StudyFlow to put what I learned into practice by turning a UI design into a fully structured and responsive webpage.

This is not intended to be a production-ready application. The main goal is to improve my front-end development skills and gain more experience building websites from scratch.

---

## Project Goals

The main goals of this project were to practice:

- Writing semantic HTML5
- Structuring a complete webpage
- CSS Flexbox
- CSS Grid
- Responsive web design
- Media queries
- CSS positioning
- Spacing and layout
- Typography
- Colors and visual hierarchy
- Cards and reusable UI components
- Hover and active states
- Progress bars and UI elements
- Creating a responsive dashboard layout

---

## Technologies

The project was built using only:

- **HTML5**
- **CSS3**

No JavaScript or CSS frameworks were used.

---

## Features

- Responsive student dashboard
- Sidebar navigation
- Dashboard statistics
- Today's tasks section
- Course progress cards
- Weekly schedule
- Study progress section
- Responsive layout for desktop, tablet, and mobile
- Interactive-looking UI states using CSS only

---

## Design

The initial UI/UX design was created with the assistance of **AI**.

The purpose of using AI was to help generate a visual design that I could use as a reference and then challenge myself to recreate it using HTML and CSS.

The **HTML structure and CSS implementation were written by me** as part of the learning process.

---

## Responsive Design

StudyFlow was designed to work across different screen sizes:

- Desktop
- Mobile
- Tablet

The layout adapts to smaller screens using CSS media queries.

- Making the design responsive
- Maintaining consistent spacing between different sections
- Creating a timetable layout
- Building reusable-looking cards
- Making the desktop design work well on mobile
